# 🗂️ 运维资料库

> 这里不转载原文。每条只做三件事：告诉你**这份资料解决什么问题**、补上**你需要的背景**、以及**我自己踩过的坑**，然后把你送到原作者那里去读。

## 关于这个库怎么用

外部资料的价值不在于"存下来"，而在于**你遇到问题时能三十秒内定位到该读哪一条**。所以这个库按"你正在排查什么"分类，而不是按技术栈分类。

每条的结构固定：

| 字段 | 含义 |
| --- | --- |
| **来源** | 原作者与站点 |
| **读它解决什么** | 什么场景下该翻出这一条 |
| **要点** | 这个主题你需要知道的背景，我写的 |
| **我的补充** | 版本限制、生产环境注意事项、我踩过的坑 |
| **阅读原文** | 直达原作者页面 |

⚠️ **要点与补充均为本人撰写**，不是原文摘录。原文的具体数据、结论请以链接为准——我不会替原作者转述他没说过的话。
