# 🎨 前端资料库

> 不转载原文。每条只做三件事：说清**这份资料解决什么问题**、补上**你需要的背景**、写下**我踩过的坑**，然后把你送到原作者那里去读。

## 关于这个库怎么用

前端的知识过期得比后端快，所以这个库刻意做了两件事：一是**优先收录规范与浏览器厂商的一手来源**（MDN、web.dev、Chrome、WebKit、Mozilla Hacks），二是每条都标注了**能力可用性的判断方式**，而不是只说"这个特性很好用"。

每条的结构固定：

| 字段 | 含义 |
| --- | --- |
| **来源** | 原作者与站点 |
| **读它解决什么** | 什么场景下该翻出这一条 |
| **要点** | 这个主题你需要知道的背景，我写的 |
| **我的补充** | 兼容性边界、降级方案、我踩过的坑 |
| **阅读原文** | 直达原作者页面 |

⚠️ **要点与补充均为本人撰写**，不是原文摘录。原文的具体数据与结论请以链接为准。
